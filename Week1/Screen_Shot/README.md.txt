### 📚 Course Description

This repository contains my practical exercises, notes, code snippets, and projects for the **Web Application Development - PHP & MySQL** course. The primary focus is building dynamic, secure, and database-driven web applications. It documents my learning journey across core PHP fundamentals, MySQL database architecture, API designs, and modern backend methodologies.

---

### 🎯 Course Objectives

By completing this course, I will learn how to:
* Develop dynamic and interactive web pages using PHP.
* Understand PHP variables, scoping, control structures, and variable rules.
* Manage complex data using arrays and reusable custom functions.
* Process and sanitize user input via HTML forms.
* Design relational databases and run optimized SQL queries.
* Implement complete CRUD (Create, Read, Update, Delete) operations.
* Build and consume REST APIs using standard JSON formats.
* Secure web applications using authentication, session control, and validation.
* Understand modern web development patterns including MVC architecture and frameworks.

* **Module 5:** Relational Database Design, SQL & MySQL Integration
* **Module 6:** Building Complete CRUD Applications
* **Module 7:** RESTful API Architecture & Data Serialization (JSON)
* **Module 8:** Security Best Practices, Hashing & Session Authentication
* **Module 9:** Architectural Patterns (MVC Design Pattern)
* **Module 10:** Modern PHP Frameworks (Laravel Overview)
